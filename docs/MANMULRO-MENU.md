# 만물로 메뉴판 만들기 V1 기능 명세서

- **문서 버전**: V1.0
- **프로젝트명**: 만물로 메뉴판 만들기
- **서비스 형태**: WordPress 기반 웹 애플리케이션 (`manmulro-menu`)
- **핵심 메시지**:
  - *"메뉴는 한 번만 입력하세요."*
  - *"기존 메뉴판이 있으면 사진으로, 없으면 직접 만들어보세요."*

---

## 1. 핵심 설계 및 개발 절대 원칙 (#2, #28)

1. **OCR과 직접 입력 시스템을 별도로 만들지 않는다**: 두 방식 모두 최종적으로 동일한 공통 메뉴 데이터 구조(`MENU_PROJECT`, `CATEGORY`, `MENU_ITEM` 등)에 저장한다.
2. **OCR 결과를 사용자 확인 없이 자동 확정/공개하지 않는다**: 낮은 신뢰도 항목은 `"확인 필요"`로 표시하며, 사용자가 `[확인하고 메뉴로 가져오기]`를 눌렀을 때만 저장한다.
3. **OCR과 직접 입력의 상호 전환**: OCR 후 `+ 메뉴 추가`가 가능하고, 직접 입력 중에도 `기존 메뉴판에서 가져오기`로 추가 OCR을 실행할 수 있다.
4. **원본 메뉴판 사진(`SOURCE_IMAGE`)과 실제 메뉴 사진(`MENU_IMAGE`)을 엄격히 구분한다**: 관리 화면에서 `[원본 메뉴판 보기]` 및 메뉴별 `[원본에서 보기]`(Bounding Box 위치 하이라이트)를 지원한다.
5. **QR 코드 불변 원칙**: 메뉴나 가격을 수정해도 기존 QR 코드와 메뉴판 고유 URL(`/menu/{store}`)은 변경되지 않는다.
6. **메뉴별 고유 상세 페이지 URL**: `/menu/{store}/{menu-item}` 구조로 각 메뉴 상세 페이지를 직접 공유할 수 있다.
7. **알레르기 및 원산지 추측 금지**: 시스템이 임의로 추측하지 않으며 사업자가 직접 입력·확인한 정보만 표시한다.

## 2. 5단계 사용자 제작 흐름 (#3)

- **STEP 1 — 시작 방법 선택**: `[사진으로 시작하기]` (OCR) 또는 `[직접 만들기]`
- **STEP 2 — 메뉴 구성**:
  - 2A: 원본 메뉴판 업로드·이미지 전처리(회전/확대/기울기/밝기·대비/자르기) → OCR Bounding Box 양방향 비교·수정·병합 → `[확인하고 메뉴로 가져오기]`
  - 2B: 업종 선택(음식점, 카페, 주점, 베이커리, 미용/뷰티, 서비스 가격표, 기타), 카테고리 관리, 메뉴 추가/수정/삭제/복제/순서 변경(Drag & Drop)/상태(`ACTIVE`, `SOLD_OUT`, `HIDDEN`)/태그(`대표 메뉴`, `인기 메뉴`, `추천 메뉴`, `신메뉴`, `매운 메뉴`), 다중 선택 일괄 관리(가격 `+500원`/`+1,000원`/`-500원`, 상태, 카테고리 이동)
- **STEP 3 — 메뉴 상세정보**: 상세 설명, 주요 재료 및 설명, 맛 특징(`●●●○○`), 추천 대상, 알레르기 정보, 원산지 정보, 기타 옵션(인분, 중량, 조리시간, HOT/ICE, 사이즈, 추가금액)
- **STEP 4 — 메뉴판 디자인**: 8종 템플릿(한식, 카페, 고급 레스토랑, 심플, 모던, 전통, 베이커리, 주점) 및 색상·글꼴·로고·이미지 표시 여부 실시간 미리보기
- **STEP 5 — 완성 및 배포**: 모바일 QR 메뉴판(`/menu/{store}`), 메뉴 상세 페이지(`/menu/{store}/{menu-item}`), 인쇄용 메뉴판(`A4`/`A3`, `세로`/`가로`, `PDF`/`JPG`/`PNG`)
